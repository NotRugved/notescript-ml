## Interview Questions

### Q1: Why is input data crucial for generating study material?

**Answer:** Without specific lecture notes, the AI cannot extract key concepts, algorithms, or facts, resulting in generic or empty output.

### Q2: How would you handle missing context in a data processing pipeline?

**Answer:** I would flag the missing data, request the source material, and avoid hallucinating content to maintain accuracy.

### Q3: What is the difference between a cheat sheet and a flashcard?

**Answer:** A cheat sheet is a condensed reference of facts, while flashcards are Q&A pairs for active recall testing.

### Q4: Why is JSON a preferred format for structured data exchange?

**Answer:** JSON is lightweight, human-readable, and easily parsed by most programming languages, making it ideal for APIs and data exchange.

### Q5: What is the importance of specifying the language style (e.g., Hinglish) in prompts?

**Answer:** It ensures the output resonates with the target audience, improving comprehension and engagement for users who prefer mixed-language technical content.
